# Phishing Awareness Training Website

A web-based cybersecurity awareness platform designed to educate users about phishing attacks, social engineering techniques, suspicious messages, and safe online practices.

## Features

- Phishing awareness information
- Common phishing warning signs
- Social engineering awareness
- Realistic phishing email example
- Interactive 5-question quiz
- Automatic quiz score calculation
- Correct and incorrect answer feedback
- Quiz progress indicator
- Responsive design for mobile devices
- Navigation between different sections

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
